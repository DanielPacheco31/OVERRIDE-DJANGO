**Personalización del Modelo de Usuario en Django.**
Este proyecto demuestra cómo crear un modelo de usuario personalizado en Django,
extendiendo la clase AbstractUser para incluir campos adicionales como tipo de sangre, 
teléfono y cédula de identidad.

**Características**
Modelo de usuario personalizado con campos adicionales.
Configuración completa para sustituir el modelo de usuario predeterminado de Django.
Ejemplo de implementación siguiendo las mejores prácticas.
